# raiffeisen Integration Guide

> Generated by forge 1.0.0 from API интеграции выплат 1.0. Решения с confidence < 0.8 перечислены в разделе «Допущения».

## Авторизация

- Тип: не найдена
- Header: —
- Хранение: `providers.credentials` (encrypted)
- Заполнить вручную: `credentials.account`

## Настройка

- ENV `RAIFFEISEN_BASE_URL` — базовый URL (default sandbox: `https://test.ecom.raiffeisen.ru/api`)
- Production: `https://e-commerce.raiffeisen.ru/api`
- `config.callback_url` — адрес приёма webhook на стороне Space Payments
- ProviderGateway config — см. раздел ниже
