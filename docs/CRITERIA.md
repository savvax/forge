# Критерии оценки → где закрываем

Зачем читать: каждая карточка в `docs/AGENT_TASKS.md` ссылается на строки отсюда. Эксперты (100)
формируют топ-5 по трём чек-поинтам; финал = техжюри (100) + отраслевое (20). Оценивают прежде всего
код в репозитории; могут развернуть. Источник — `описание.docx`.

## Ограничения (нарушение = дисквалификация)

Только open-source; большинство кода на Ruby (ядро — чистый Ruby, никаких обёрток над другим языком);
нейросети внутри проекта запрещены (AI-ассистированная разработка — можно); коммит после стоп-кода —
дисквалификация.
