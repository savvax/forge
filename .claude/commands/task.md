Сделай задачу $ARGUMENTS из docs/AGENT_TASKS.md.

1. Найди карточку $ARGUMENTS. Прочитай только те разделы docs/, что указаны в её поле «Читать».
2. Меняй только файлы из поля «Владеет». Если нужен чужой файл — остановись и спроси меня.
3. Сначала напиши тесты на каждое ожидаемое значение из поля «Тесты» (они должны быть красными),
   затем реализацию, затем добейся зелёного `bundle exec rake check` (rubocop 0, rspec 0 failures,
   SimpleCov не ниже порога).
4. Если команда уже существует, проверь, что
   `bin/forge generate --spec examples/specs/novapay.yaml --out tmp/out --force` не сломалась.
5. Обнови README.md, если изменилось поведение CLI, и NOTES.md → «Решения», если принял
   архитектурное решение (формат D-xx: Контекст / Решение / Альтернативы / Следствия).
6. Сделай коммит `<module>: <what>` (на английском).
7. В конце напиши мне 5–7 предложений: что сделано; какие решения принял и почему; что проверить
   руками (команда + ожидаемый вывод); что осталось; как объяснить это экспертам за 2 минуты.

Если не помещаешься в сессию — остановись на зелёном состоянии, запиши остаток в карточку
(подраздел «Остаток») и скажи мне об этом. Никаких «почти работает».
